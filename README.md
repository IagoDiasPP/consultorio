\# Sistema de Consultório



Sistema full stack para gerenciamento de um consultório médico, com cadastro de pacientes, agendamentos e gerenciamento básico.





\## Objetivo



Este projeto foi desenvolvido com o objetivo de praticar desenvolvimento full stack, integrando frontend e backend, simulando um sistema real de consultório.





\## Tecnologias utilizadas



\### Front-end

\- React (Vite)

\- JavaScript

\- HTML + CSS

\- Axios



\### Back-end

\- Java

\- Spring Boot

\- Spring Data JPA

\- Maven





\## Estrutura



Consultorio/

&#x20;├── front/   (React)

&#x20;├── back/    (Spring Boot)



\## Como executar



\### Backend

cd back

./mvnw spring-boot:run



\### Frontend

cd front

npm install

npm run dev



\## Comunicação



O frontend consome a API do backend via REST (HTTP).
